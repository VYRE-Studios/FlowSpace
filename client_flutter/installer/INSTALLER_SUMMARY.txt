WHAT IS THIS?
═════════════════════════════════════════════════════════════════════════
Complete NSIS-based installer system for FLŌ (Teams. Unified.)
Provides professional Windows installers with:
  • No admin rights required
  • Portable USB versions
  • Automated build scripts
  • Professional user experience


QUICK START (5 MINUTES)
═════════════════════════════════════════════════════════════════════════
1. Install NSIS: choco install nsis
2. Run: .\build-installer.ps1
3. Done! You'll have FLO-1.0.0-Setup.exe

BUILD COMMANDS (COPY-PASTE)
═════════════════════════════════════════════════════════════════════════

# Clean build with specific version
.\build-installer.ps1 -Version "1.0.1" -Clean

# Build with verbose output
.\build-installer.ps1 -Verbose

# Quick rebuild (skip Flutter build)
.\build-installer.ps1 -SkipFlutterBuild

INSTALLATION LOCATIONS

  %APPDATA%\com.example\client_flutter\flowspace.db

  (Stored in database-configured location)

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════

Problem: "NSIS not found"
→ Install NSIS: choco install nsis
→ Or download from: https://nsis.sourceforge.io/Download

Problem: "Flutter build failed"
→ Run: flutter doctor
→ Ensure: flutter build windows --release works

Problem: Installer won't run
→ Right-click → Properties → Unblock
→ Or sign installer for production use

Problem: Files missing after install
→ Verify Flutter build output exists
→ Check NSIS script File commands


CUSTOMIZATION
═════════════════════════════════════════════════════════════════════════

Change Version:
  Edit flo-installer.nsi:
    !define PRODUCT_VERSION "1.0.0"

Change Publisher:
  Edit flo-installer.nsi:
    !define PRODUCT_PUBLISHER "Your Company Name"

Change Install Location:
  Edit flo-installer.nsi:
    InstallDir "$LOCALAPPDATA\YourAppName"


CODE SIGNING (OPTIONAL)
═════════════════════════════════════════════════════════════════════════

2. Install Windows SDK (includes signtool.exe)
3. Edit build-installer.ps1 (lines 176-177)
4. Add signing command with certificate details

Benefits:
